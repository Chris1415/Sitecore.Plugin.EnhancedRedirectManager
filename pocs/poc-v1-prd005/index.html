"Quiet Diagnostic" — upstream drift detection surface inside the existing Test tab. Chrome-neutral, muted-foreground, informational instrumentation (not alarm). Drift surfaces via three additions: a secondary "Check upstream" button below the Test button, an inline status block, and a muted banner above the trace area.
