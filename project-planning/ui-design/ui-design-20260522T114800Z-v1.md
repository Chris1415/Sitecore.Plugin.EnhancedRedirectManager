## 1. Design intent (≤ 60 words)

- **Named direction:** *Quiet Diagnostic* — a chrome-neutral, muted-foreground micro-surface stitched into the existing Test-tab left rail. **Two-tier tone (amended 2026-05-26):** idle / checking / in-sync stay muted-informational; **drifted escalates to destructive (red) tone + `AlertTriangle` glyph**; error sub-states use warning (amber) tone. A11y semantics (`role="status"`) preserved across all states.
- **Why this direction:** Operators run drift checks during a normal day; muted baseline keeps that calm. But drift IS the load-bearing signal — operator feedback 2026-05-26 confirmed it needs visual weight. Errors are recoverable via retry so they sit one tier below drift.
- **Divergence from other variants:** None — single variant per `scope_dial.ui_variants = 1`.

## 2. Inherited baselines (link only, do not redescribe)

- **PRD-002 V4 Blok Elevated** tokens: `--color-muted`, `--color-muted-foreground`, `--color-border`, `--color-card`, `--color-foreground`, `--color-primary`, `--color-success-100/500/600`, `--radius-md`, `--space-*` — see `pocs/poc-marketing-v4-blok-elevated/theme.css`. **Light + dark + system** flip via `.dark` on `<html>`; system follows `prefers-color-scheme`.
- **Motion budget:** ADR-0024 (160 ms ease-out for state transitions) + ADR-0027 (full `prefers-reduced-motion: reduce` short-circuit to instant render). PRD-005 adds no new motion primitives.
- **Test-tab two-column anatomy:** left rail (URL input + existing Test button + maps list) | right column (trace area) — established in PRD-004. PRD-005 inserts two new pieces into this layout *without* changing column widths, gutter, or breakpoint stacking behavior.
- **Accessibility floor:** WCAG 2.1 AA, ≥ 4.5:1 text contrast in both themes, visible focus ring on every interactive primitive.

**Banner copy (final, operator-approved):**
- **Drifted:** `Upstream `RedirectsProxy` has changed since this simulator was ported. Trace may be subtly inaccurate. Ask your engineer to run `/sync-redirect-proxy` to update. (Last sync: <retrievedAt>).` — `<retrievedAt>` rendered as both an absolute ISO date (e.g. "May 20, 2026") AND a relative hover-title `title="2 days ago"`.
- **In-sync (inline, not the banner):** `In sync with upstream `dev` (checked <relative>).`
- **Error states (inline, not the banner):** per AC-2.1 / 2.2 / 2.3 — copy lives in code as a single `ERROR_COPY[reason]` map; rate-limit minutes injected by hook (`retryAfterSeconds`).

**Resolved: OQ-7 — banner tab-order placement.** Tab order on the Test tab is: URL input → existing Test button → **Check upstream button** → (banner DOM block) → trace area. The banner sits in DOM order AFTER the Check button and BEFORE the trace; its dismiss `@blok/icon-button` is keyboard-reachable in that slot. `role="status"` does NOT inject into tab order until focused. Operators who do not Tab into the banner are not blocked by it — pressing Tab from the Check button moves to the dismiss X (1 stop), then to the trace area. Screen readers announce the banner content via `aria-live="polite"` when it first appears, regardless of tab focus. This matches the architecture recommendation ("after Test button, informational, not alert") verbatim.

## 6. Accessibility notes (verified on the POC)

- **Contrast ratios** (computed on the POC via `getComputedStyle`, light + dark): banner copy `text-muted-foreground` on `bg-muted` ≥ 4.6 : 1 light, ≥ 4.7 : 1 dark; inline `in-sync` text `text-muted-foreground` on `bg-background` ≥ 7.0 : 1 both themes; success-tick icon `text-success-600` light / `text-success-500` dark on `bg-background` ≥ 3.1 : 1 (icon — non-text, AA threshold met); Check-upstream button label on `bg-secondary` ≥ 5.2 : 1 light, ≥ 8.5 : 1 dark.
- **Keyboard flow:** Tab cycles URL input → Test button → Check upstream button → (drift banner dismiss X — only when banner is rendered) → trace area / row affordances. Enter / Space activate every button. Esc on the banner dismiss X also dismisses (POC verified).
- **Focus rings:** every interactive primitive uses Blok's standard `--ring` token outline at 2 px offset. Visible in both themes against `bg-muted` (POC measured ≥ 3 : 1 indicator contrast).
- **`role="status"` + `aria-live="polite"`** on the banner — announces drift copy to screen readers without interrupting the operator's current focus. **NOT** `role="alert"` (would force-interrupt, wrong for informational signal). Dismiss button carries `aria-label="Dismiss upstream drift banner"`.
- **Reduced motion:** the button "Checking…" spinner short-circuits to a static `⟳` glyph when `prefers-reduced-motion: reduce`; banner enter / exit transitions short-circuit to instant render. POC includes the `@media (prefers-reduced-motion: reduce)` block.
- **Color-emoji discipline (Blok theming pitfall):** all state icons are Lucide glyphs (`Check`, `Info`, `X`) rendered as inline SVG with `currentColor`, NOT emoji codepoints. No `❌` / `✅` / `⚠️` anywhere — these would render as platform color bitmaps that ignore theme and contrast.
