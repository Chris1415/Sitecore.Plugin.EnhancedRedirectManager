## 1. Summary

PRD-005 closes the parity contract introduced by PRD-004 over time, not just at port time. The simulator's verbatim port of upstream `RedirectsProxy` (PRD-004, ADR-0038) is now monitored continuously through two layered pieces: an **on-demand drift detector** inside the Test tab (SHA-mismatch only, sequential GitHub commits API call per watched file, 5-state machine per ADR-0049) and a **dev-time `/sync-redirect-proxy` slash command** in the product repo's `.claude/commands/` that proposes a verbatim re-port via Claude Code's edit flow, regenerates fixtures via the existing AST extractor (ADR-0042), runs the test suite, and on accept auto-bumps the snapshot SHA. The baseline SHA + retrieval metadata moves out of the simulator's header comment into a dedicated `__fixtures__/upstream-snapshot.json` (ADR-0044) — JSON is the source of truth; header is documentation. The `originalPort` field preserves PRD-004's `dev`-branch provenance as an audit anchor. Tracked branch is `dev` for v0 (ADR-0044 amended at /architect after a live probe found `Sitecore/content-sdk@main` 404s for the watched files — promote to `main` via single-line snapshot edit when Sitecore publishes it). UI direction is *Quiet Diagnostic* with a two-tier tone (drifted=destructive red + AlertTriangle, errors=warning amber, in-sync=success green; `role="status"` preserved across all states per ADR-0045 amendment). Zero new Sitecore SDK surfaces; one new HTTP integration (unauthenticated GitHub commits API). Zero CSP changes (ADR-0048 — verified `next.config.mjs` empty at /architect). The operator validated drift end-to-end on localhost during the live walkthrough (forced snapshot SHAs to `0000…` → destructive banner with AlertTriangle rendered; reverted SHAs → in-sync inline status with green Check rendered), surfacing three rounds of UX iteration (toolbar split, trace-card grid pack, double-scrollbar fix) that landed in the same PR. 761/761 tests GREEN, build clean, lint at PRD-004 baseline. Status: `shipped_with_caveats` — same pattern as PRD-002/003/004 (host-frame Playwright deferred + live walkthrough pass_with_caveats).

## 4. Known Limitations

- **Snapshot bump latency** — engineer-side `upstream-snapshot.json` SHA bumps reach the deployed app only after the next Vercel build + deploy (the snapshot is bundled at build time via static import). Operators clicking "Check upstream" between slash-command success and deploy completion see the stale baseline (and the drift banner). Documented in AC-3.8's success message ("The in-app baseline updates after the next deploy.") and PRD R8.
- **GitHub API rate limit (60 req/hr/IP)** — unauthenticated v0 per ADR-0046. A team sharing an egress IP could hit this quickly under heavy use; on-demand-only traffic (D3) keeps typical per-operator usage at ~10/hr. **Recovery:** banner shows `retryAfterSeconds` from the `X-RateLimit-Reset` header; PAT auth is FO-5.2.
- **Tracked branch is `dev`, not `main`** — ADR-0044 was amended at /architect after a live probe found `Sitecore/content-sdk@main` 404s for the watched files (repo default branch is `dev`). `dev` is the v0 target. **Recovery:** promote via single-line snapshot edit (`branch: "main"`) once Sitecore publishes `main`. No code change required.
- **`compareSnapshot()` silent-in-sync for missing paths** — `sync-helpers.ts:47` treats `watchedFiles[]` entries whose `path` doesn't appear in the live response as in-sync rather than surfacing as a path-rename error. Safe for current 2-file watch; documented as a known edge case at /code-review (m4 minor, accepted).
- **`isRegexOrUrl("/")` returns `'regex'`** — degenerate-case upstream behavior, replicated verbatim per ADR-0038 (PRD-004 carry-forward). Documented in `proxy-simulator.ts` header.
- **`live_walkthrough: pass_with_caveats`** — operator validated drift detection end-to-end on localhost (forced snapshot to drifted state, reverted to in-sync) but did not run the full `/sync-redirect-proxy` slash command nor exercise the manual X-click dismiss. - **Host-frame visual diff skipped** — same as PRD-002/003/004. Localhost render + component tests are the visual verification this PRD.
